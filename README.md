# Student Expense Tracker

## 📌 Project Overview

Student Expense Tracker is a web-based application designed to help students
manage and track their daily income and expenses easily.

The application provides a simple dashboard where users can add, edit,
delete, search, and filter their financial transactions.

All transaction data is stored in the browser using LocalStorage, so the data
remains available even after refreshing the page.

---

## 🎯 Objectives

- To provide an easy way to manage daily expenses.
- To track income and expenses in one place.
- To calculate total income, total expenses, and balance automatically.
- To provide search and filtering functionality.
- To store transaction data using browser LocalStorage.
- To create a responsive and user-friendly web application.

---

## ✨ Features

- Add income transactions
- Add expense transactions
- Edit transactions
- Delete transactions
- Search transactions
- Filter by transaction type
- Filter by category
- Automatic balance calculation
- Dashboard with financial summary
- LocalStorage data persistence
- Dark Mode / Light Mode
- Responsive design for mobile and desktop
